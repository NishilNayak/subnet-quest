Glossary

Bit
A single 0 or 1, the smallest piece of data.
Binary
Counting with only 0s and 1s. Each position is worth double the one to its right.
Octet
A group of 8 bits. An IPv4 address has four, each worth 0–255.
IP address
A device’s address on a network, e.g. 192.168.1.42.
Network part
The bits that identify which network (street) a device is on.
Host part
The bits that identify the device (house) on that network.
Subnet mask
32 bits: 1s mark the network part, 0s mark the host part. E.g. 255.255.255.0.
CIDR / prefix
Shorthand for a mask: /24 means 24 network bits (ones).
Subnet
A smaller network carved out of a bigger one.
Network address
The first address of a subnet (host bits all 0). It names the subnet and isn’t given to a device.
Broadcast address
The last address of a subnet (host bits all 1). Sends to every device on it.
Usable hosts
Addresses you can give to devices: 2host bits − 2.
Block size
256 minus the mask value in the interesting octet. How far apart subnets are.
IP class
The old system (A–E) that set the mask from the first octet.
Private address
Used inside homes and offices (10.x, 172.16–31.x, 192.168.x), not on the internet.
Router
A device that moves traffic between different networks.
Default gateway
The router a device sends traffic to when the destination is on another network.
DHCP
A service that hands out IP addresses automatically.
NAT
Lets many private addresses share one public address.
Loopback
127.0.0.1, a device talking to itself (“localhost”).
